# ダービー馬暗記帳

日本ダービー（東京優駿）の歴代優勝馬を覚えるための Web アプリ。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。

## 機能

- **一覧**：全優勝馬を年代別に表示・検索
- **切り口**：騎手別・調教師別・父別・母の父別・年代別・人気別にまとめて表示
- **暗記カード**：年 ⇄ 馬名 のフラッシュカード
- **クイズ**：4択／入力。年・馬名・騎手・調教師・父・母の父を出題
- **復習**：間違えた問題だけを再出題（正解するとリストから外れる）

成績と復習リストはブラウザの localStorage に保存されます。

## ファイル

| ファイル | 内容 |
|---|---|
| `data.js` | 優勝馬データ |
| `app.js` | アプリ本体 |
| `style.css` | 見た目 |

## データ出典

Wikipedia 日本語版「東京優駿」および各馬の記事（CC BY-SA 4.0）

## 更新時の注意

スマホが古い CSS / JS を使い続けないよう、`index.html` で読み込むファイルに `?v=…` を付けています。
CSS・JS・データを変更したら、この値を新しくしてから公開してください。
